# MATH2001 — Problem Set 3 (Limits)

Due: before Friday lab (bring solutions to LT210).

1. Evaluate lim x→2 (x² − 4)/(x − 2), or state that it does not exist.
2. Find the left- and right-hand limits of f(x) = |x|/(x) as x→0.
   Is the two-sided limit defined? Justify.
3. For f(x) = sin(x)/x, use the squeeze theorem to show lim x→0 f(x) = 1.
4. Let g(x) = { x+1, x < 1 ; 3, x = 1 ; x², x > 1 }.
   Is g continuous at x = 1? Classify the discontinuity if not.
5. Use the Intermediate Value Theorem to argue that x³ + x − 1 = 0 has a
   solution in (0, 1).

Hints (lecture week 4):
- Q1: factor before evaluating.
- Q3: −1 ≤ sin(x)/x ≤ 1 for x near 0.
- Q5: check signs at the endpoints.
