DynaCalendar — the web UI is not built yet

The API is running, but web/dist/ is missing. Vite is the only build step in this repo, so build the three pages once: 

cd web
npm install
npm run build

Then reload http://127.0.0.1:8000. For frontend development instead, run npm run dev (port 5173, proxies /api to 8000) and use that URL.

Docker users: docker compose up --build builds the frontend for you.
